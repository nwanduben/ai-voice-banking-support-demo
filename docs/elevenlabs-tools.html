ElevenLabs tools: copy & paste sheet

ENTIN Bank · 13 webhook tools · each has its own webhook in n8n (node "Webhook: <tool name>") at https://qr4v3tgj.rcld.app
For each tool below: ElevenLabs → your agent → Tools → Add tool → Webhook.
  1. Copy in the Name, Description, Method and URL.
  2. Under Headers, add Authorization and choose the secret ENTIN_TOOL_SECRET (value: Bearer YOUR-SECRET).
  3. Under Body parameters, add each row. For conversation_id, set the value type to Dynamic variable and choose system__conversation_id. For everything else, choose LLM prompt and paste in the description.
The URLs use /webhook/, not /webhook-test/. They only work while workflow 1 – Live call tools is active in n8n.
