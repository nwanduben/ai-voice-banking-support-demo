How a call works: the caller speaks to the ElevenLabs agent. Whenever the agent needs information, it asks n8n. n8n reads or updates the Google Sheet and sends the answer back. The agent then speaks that answer to the caller.

2 Set up n8n ~10 min

2a. Make a secret password

This is a long random password that lets ElevenLabs talk to n8n. Run this in Terminal and copy the result:

openssl rand -hex 24

We'll call it YOUR-SECRET. Keep it somewhere safe, because you'll paste it twice.

2b. No server settings needed

These workflows work on RepoCloud as they are. Your sheet link and your alert email (nwanduben@gmail.com) are already written into them, so there's nothing to add to your n8n server.

2c. Create 3 credentials in n8n

In n8n, go to Credentials → Add credential:

2d. Import the 5 workflows

In n8n, go to Workflows → Import from file, once per file in the n8n/ folder. Then in each workflow:

  • Open every node that shows a red warning and select the matching credential from 2c. Workflow 1 has 13 webhook nodes on the left, one per tool, named like Webhook: verify_caller. Each one needs ENTIN Webhook Auth.
  • Save the workflow.

  • Open 5 – Reset demo and click Execute workflow. This puts Gerald's test payment at "yesterday, 4pm".

3 Set up the ElevenLabs agent ~15 min

Go to ElevenLabs → Agents → Create agent and choose Blank agent. Name it ENTIN Bank – Ada.

3a. Words the agent says

  • First message: paste in the contents of agent/first-message.txt.
  • System prompt: paste in the contents of agent/system-prompt.md.
  • Knowledge base: upload the 4 files in agent/knowledge-base/ and turn on RAG.

3b. Voice and brain

  • Voice: pick a Nigerian-accented English voice from the Voice Library.
  • LLM: pick a model that's good at tool calling, and set temperature to about 0.3.
  • Language: English, plus Hausa, Yoruba and Igbo if they're offered. Turn on Language detection.

3c. Connect the tools (the agent's "hands")

  • Go to Secrets → New secret. Name it ENTIN_TOOL_SECRET, set the value to Bearer YOUR-SECRET, and copy its secret ID.
  • In Terminal, from the project folder, run the command below. Replace the n8n address and secret ID with yours.
N8N_BASE=https://your-n8n-address ELEVENLABS_SECRET_ID=paste-secret-id python3 agent/build_tools.py
  • This creates 13 files in agent/tools/. Add each one as a Webhook tool in the agent.
  • In every tool, set conversation_id to the dynamic variable system__conversation_id.
  • Turn on the system tools End call and Transfer to number (use your own phone number).

3d. After-call summary

  • Go to Analysis and add the evaluation criteria and data fields from agent/evaluation.json.
  • Set the Post-call webhook to https://your-n8n-address/webhook/entin-post-call.
  • Copy the webhook's HMAC secret. In n8n, open workflow 2 – Post-call summary, then the node HMAC with ElevenLabs Secret. Replace PASTE_ELEVENLABS_WEBHOOK_SECRET_HERE in the Secret box with it, and save.

3e. Put it on your website

  • Go to the Widget tab, copy the embed code, and paste it into your portfolio page.
Note: "Transfer to a human" only works on real phone calls. On the website widget, the agent logs the handoff in the Escalations tab and emails you instead. Once you buy a Nigerian number, transfers will ring your phone.

Open the widget and play Gerald. Say:

"Good morning, my name is Gerald. 70,000 naira was deducted from my account yesterday and I don't understand why."

Open the Google Sheet and watch it change:

  • Cards: Gerald's card changes to blocked_fraud

After each demo, run 5 – Reset demo in n8n so Gerald is ready again.
